Політика конфіденційності

💡 Остання редакція:

1. Які дані ми зберігаємо

  • Дані акаунту: email, ім'я, хешований пароль (PBKDF2, 100k ітерацій)
  • Клієнти та проєкти: імена, контакти, нотатки (введені вами)
  • Фінансові дані: інвойси, витрати, банківські реквізити (захищені маскуванням)
  • Королики: баланс та історія транзакцій
  • Логи активності: дії в застосунку для зручності

2. Як ми захищаємо ваші дані

  • Паролі зберігаються у вигляді хешу (PBKDF2 + SHA-256) — оригінал не зберігається
  • Номери карток маскуються (видно лише перші 6 та останні 4 цифри)
  • При підключенні Supabase — дані шифруються при передачі (HTTPS/TLS)
  • Row Level Security (RLS) у Supabase — користувач бачить лише свої дані
  • Локальні дані (localStorage) не передаються третім сторонам

3. Email-верифікація

При реєстрації на ваш email надсилається лист із посиланням для підтвердження акаунту. Після переходу за посиланням акаунт активується. Листи надсилаються через Supabase Auth.

4. Внутрішня віртуальна валюта (Королики 👑)

На платформі використовується внутрішня віртуальна валюта «Королики», яку можна поповнювати та використувати для розрахунків всередині застосунку (наприклад, для оплати AI-інструментів). Баланс Короликів зберігається в базі даних Supabase (таблиця profiles) і синхронізується з інтерфейсом користувача.

У майбутньому на платформі можуть підключатися реальні платні сервіси та платіжні шлюзи для поповнення балансу і проведення розрахунків. Про будь-які зміни, що стосуються обробки коштів, буде повідомлено в цій Політиці.

5. AI-інструменти (Voice-to-Text, OCR)

При використанні AI-інструментів (50 Короликів за запуск):

  • Voice-to-Text: розпізнавання виконується локально (Web Speech API) — аудіо не передається на сервер
  • OCR: за замовчуванням Tesseract.js (локально в браузері). При наявності OpenAI ключа — фото передається до OpenAI Vision API
  • Списання Короликів — атомарна операція (захищена на рівні даних)

6. Передача даних третім сторонам

Ми не продаємо та не передаємо ваші дані третім сторонам. Винятки:

  • Supabase (якщо підключено) — зберігання та синхронізація даних
  • OpenAI (тільки якщо ви додали API-ключ) — для OCR розпізнавання
  • Платіжні шлюзи (WayForPay, LiqPay, Stripe) — при проведенні платежів

7. Ваші права (GDPR)

Ви маєте право: запитати видалення всіх даних (Налаштування → Скинути дані), експортувати дані (JSON), та відмовитись від використання.
