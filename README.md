# FreelanceHub Pro

Вебзастосунок для фрілансерів: управління клієнтами, проєктами, інвойсами, витратами та воронкою продажів. Містить AI-помічника, внутрішню валюту «Королики» та реальну систему оплати через Monobank.

## Реалізовані функції

- Реєстрація та вхід з підтвердженням пошти через EmailJS (5-значний код).
- Управління клієнтами, проєктами, інвойсами, витратами, угодами.
- Воронка продажів (Deals) та журнал активностей.
- AI-помічник: Voice-to-Text та OCR документів.
- Внутрішня валюта «Королики» з щоденним бонусом та поповненням через Monobank.
- Реальна оплата через особисту Банку Monobank з QR-кодом та автоматичним нарахуванням.
- Telegram-бот для сповіщень про поповнення балансу та важливі події.
- Синхронізація даних із Supabase (PostgreSQL), підтримка офлайн через localStorage.
- Мультимовний інтерфейс (10 мов), темна/світла тема.
- Генерація та друк PDF-інвойсів.

## Технології

Vanilla JavaScript, Tailwind CSS (CDN), Chart.js. Розробка в Kiro IDE.

Зовнішні сервіси: Supabase (база даних та автентифікація), EmailJS (верифікація пошти), Monobank Personal API (прийом платежів), QRserver API (генерація QR-кодів), Telegram Bot API (сповіщення), Vercel (хостинг та serverless-функції).

## Встановлення та запуск

Нічого встановлювати не потрібно. Відкрийте `api/app/index.html` у браузері — застосунок запускається без сервера. Supabase підключено автоматично (вбудовані ключі).

Для повної функціональності (вебхуки, Telegram, Monobank) задеплойте проєкт на Vercel і додайте змінні середовища (див. нижче).

## Сценарій демонстрації

1. Відкрийте `index.html` → зареєструйтесь → введіть код із пошти.
2. Перейдіть на Dashboard — побачите демо-дані (клієнти, інвойси, витрати).
3. Натисніть **👑 [баланс]** у шапці → «💳 Поповнити Королики» → оберіть тариф → відскануйте QR у Monobank.
4. Не змінюйте коментар `PLxxxx` при оплаті — баланс оновиться автоматично за 3–5 секунд.
5. Перейдіть до Клієнти → додайте клієнта → створіть проєкт → виставте інвойс → роздрукуйте PDF.
6. AI-помічник: натисніть мікрофон або завантажте фото документа (потребує 50 Короликів).

## Перевірки, виправлення й відомі обмеження

**Перевірено:**
- Реєстрація з некоректним email → блокується з повідомленням.
- Введення невірного 5-значного коду → «Невірний код, спробуйте ще раз».
- Повторна реєстрація з тим самим email → «Вже зареєстровані, увійдіть».
- Оплата без коментаря PLxxxx → вебхук ігнорує транзакцію.
- Недостатньо Короликів для AI → блокується з підказкою отримати бонус.

**Виправлено:**
- Помилка входу при непідтвердженій пошті — тепер показує форму повторного коду.
- Баланс не оновлювався після поповнення без перезавантаження — виправлено через polling.

**Відомі обмеження:**
- Якщо модалку оплати закрити до підтвердження транзакції — Королики нарахуються, але баланс оновиться лише при наступному вході (не в реальному часі).
- Monobank вебхук потребує одноразового налаштування після деплою на Vercel.

## Змінні середовища для Vercel

| Змінна | Призначення |
|---|---|
| `MONO_JAR_ACCOUNT_ID` | ID банки Monobank (з `/personal/client-info`) |
| `SUPABASE_URL` | URL Supabase-проєкту |
| `SUPABASE_SERVICE_ROLE_KEY` | Service role key (не anon) |
| `TELEGRAM_BOT_TOKEN` | Токен бота @mICaB_Bot |
| `TELEGRAM_CHAT_ID` | Chat ID адміна |

## Активація вебхуків після деплою

**Monobank:**
```bash
curl -X POST https://api.monobank.ua/personal/webhook \
  -H "X-Token: ВАШ_ТОКЕН" \
  -H "Content-Type: application/json" \
  -d '{"webHookUrl":"https://ВАШ_ДОМЕН.vercel.app/api/mono-jar-webhook"}'
```

**Telegram:**
```
https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://ВАШ_ДОМЕН.vercel.app/api/telegram-webhook
```
